# Multilingual AI-Based Customer Review Sentiment Analyzer

## 📌 Project Overview

The **Multilingual AI-Based Customer Review Sentiment Analyzer** is a software application designed to analyze customer reviews and identify their sentiment, such as **Positive, Negative, or Neutral**. The project helps businesses understand customer feedback and gain useful insights from large amounts of review data.

## 🎯 Objective

The main objective of this project is to automate customer feedback analysis using AI-based text processing and provide a simple way to understand customer sentiment.

## 🚀 Key Features

- Analyze customer reviews
- Identify positive, negative, and neutral sentiment
- Support for multilingual customer feedback
- REST API-based backend
- Database integration
- Simple and user-friendly application structure
- Efficient processing of customer review data

## 🛠️ Technologies Used

- **Java 17**
- **Spring Boot**
- **Spring Data JPA**
- **Hibernate**
- **H2 Database**
- **Maven**
- **REST APIs**
- **AI/NLP-based text processing**

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Nikhitha03112006/multilingual-ai-customer-sentiment-analyzer.git
```

### 2. Open the project

Open the project in **IntelliJ IDEA**.

### 3. Build the project

```bash
mvn clean install
```

### 4. Run the Spring Boot application

```bash
mvn spring-boot:run
```

The application will run on the configured local server port.
